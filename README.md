# AI-Powered Smart Retail & Customer Intelligence Platform

A production-ready FastAPI backend that combines **Computer Vision**, **NLP**, and **AI Chatbot** capabilities into a single deployable service for retail and e-commerce businesses.

## Features

| Module | Capability | Technology |
|--------|-----------|------------|
| **Face Recognition** | Identify returning vs. new customers | OpenCV LBPH |
| **Product Classifier** | Classify product images into retail categories | TensorFlow CNN (Fashion-MNIST) |
| **Sentiment Analysis** | Analyse customer reviews & feedback | Scikit-learn TF-IDF + Logistic Regression |
| **FAQ Chatbot** | Answer common retail questions | Rule-based intent matching |
| **Dashboard** | Aggregate visit & sentiment stats | FastAPI REST endpoint |

## Setup & Installation

### Prerequisites
- Python 3.10+
- pip

### 1. Clone & install dependencies

```bash
git clone <repo-url>
cd smart-retail-ai

# (Optional but recommended) create a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/macOS

pip install -r requirements.txt
```

### 2. Generate model files (run once)

Run all training notebooks in sequence:
```bash
python notebooks/train_models.py
```

Or run them individually:
```bash
python notebooks/01_chatbot_training.py        # Chatbot intent model
python notebooks/02_face_recognition_setup.py  # LBPH face recognizer
python notebooks/03_sentiment_model_training.py # TF-IDF sentiment model
python notebooks/04_image_classifier_training.py # CNN product classifier
```

### 3. Start the API server

```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

Then open **http://localhost:8000/docs** for the interactive Swagger UI.

| Method | Endpoint | Description |
|--------|----------|-------------|

## Ethics & Privacy

Face recognition in retail raises important considerations:
- **Consent**: Customers must explicitly opt in before biometric data is collected.
- **Data Privacy**: Face encodings must be stored securely (never shared with third parties).
- **Bias**: Models trained on limited demographics can be biased — use diverse datasets in production.
- **Legal Compliance**: GDPR/CCPA may require explicit legal basis for biometric data collection.
- **Data Minimization**: Only store what is necessary; delete encodings when no longer needed.

> This demo uses synthetically generated face images for testing only.
